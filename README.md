# GPIO-Driver--STM32

This repository contains a GPIO driver for STM32, developed as part of the IEEE Alexandria University Student Branch, Embedded System Team.

## Technologies Used
- Microcontroller: STM32
- Development Environment: Eclipse
- Programming Language: C

## Functionality
The GPIO driver provides functions for configuring and controlling General Purpose Input/Output pins on the STM32 microcontroller. This includes setting pin modes (input, output, analog, etc.), reading and writing pin states, and configuring pin speeds and pull-up/pull-down resistors.
